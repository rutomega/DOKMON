# DokMon - Sistem Pengingat Dokumen Otomatis

DokMon adalah aplikasi web yang dirancang untuk membantu pengguna mengingat dan mengelola dokumen penting secara otomatis. Aplikasi ini menyediakan antarmuka pengguna yang sederhana dan intuitif untuk login dan mengakses fitur-fitur pengingat dokumen.

## Fitur Utama

- **Login Karyawan**: Pengguna dapat masuk ke dalam sistem menggunakan kredensial mereka.
- **Pengingat Dokumen**: Sistem akan mengingatkan pengguna tentang dokumen yang perlu diperhatikan.
- **Antarmuka Pengguna yang Ramah**: Desain yang bersih dan mudah digunakan.

## Instalasi

1. Clone repositori ini ke mesin lokal Anda.
   ```
   git clone <URL_REPOSITORI>
   ```
2. Masuk ke direktori proyek.
   ```
   cd dokmon
   ```
3. Instal dependensi yang diperlukan.
   ```
   npm install
   ```

## Menjalankan Aplikasi

Untuk menjalankan aplikasi, gunakan perintah berikut:
```
npm start
```
Aplikasi akan berjalan di `http://localhost:3000`.
